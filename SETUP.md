# Install this GitHub profile README

1. On GitHub, create a **public** repository named exactly `raysofgoodness`.
2. Keep the generated `README.md` option unchecked if you plan to upload these files directly.
3. Upload `README.md` and the entire `assets/` folder from this package.
4. Commit to the repository's default branch.
5. Open `https://github.com/raysofgoodness` and verify the banner and badges.

Repository structure:

```text
raysofgoodness/
├── README.md
└── assets/
    └── hero-fullstack.svg
```

The profile README appears automatically because the repository name matches the GitHub username.
